DEFECT 1 — F13 (High): memory.write / memory.call_the_day revision authorization ignores device_scope.
A device with write on project P can target another device's device-private item (device_scope `device:<other>` or `class:<other>`) by logical_id: it gets E_VERSION_CONFLICT{current_version_id} (existence + head oracle; logical ids are sequential), and on retry with that head it SUPERSEDES the private item. Same via call_the_day `expected_versions` and `card_update`. Required: a revision target (and every expected_versions / card target) whose current segment(s) fail the caller's read authorization (spec §4.4 (a): project membership + device_scope) must behave exactly as if it did not exist — uniform E_NOT_FOUND, no head disclosure, nothing written. Repro: docs/bakeoff/r1/repro/test_f13_revision_ignores_device_scope.py and test_f13b_overwrite.py.

DEFECT 2 — G-B = F11 (High) + F14 (Medium): a request or stream pins a pooled DB connection and the device-row lock for its whole lifetime.
The middleware opens the transaction and takes FOR SHARE on the device row BEFORE the request body is read, and keeps the pooled connection for the full request or SSE stream. Consequences confirmed: (a) a trusted device trickling a large /mcp body blocks the admin's revoke (FOR UPDATE) indefinitely; (b) a few slow or idle requests (slow bodies, idle authenticated SSE GET /mcp streams, unauthenticated /devices/register bodies when HLM_REGISTRATION_SECRET is unset) exhaust the pool and stall the whole API. Required: read and size-cap the body BEFORE acquiring a connection or any lock (a hard maximum, configurable, with 413 on excess and a read timeout); an idle SSE stream must not hold a pooled connection or a lock while idle; revocation must always complete within a bounded time regardless of other clients; add DB-side safety nets (lock_timeout / statement_timeout / idle_in_transaction_session_timeout on the pool) with sane defaults. Keep D-024 wire behaviour, commit-before-ack for finite responses, and commit-before-headers for SSE (see D-029/D-030 and tests/integration/test_g6_commit_ack.py). Repro: docs/bakeoff/r1/repro/test_f11_slow_body.py, test_f14_sse_pins_pool.py.
