## Checked and found sound
- Cursor HMAC bound to device plus `token_generation`, and revoke bumps the generation (auth/cursors.py:53-80; db/auth_queries.py:116-130).
- Device 1 rebinds or disables on every start, before the listener opens, in one transaction (db/auth_queries.py:133-163; server/app.py:248-285).
- Commit-before-ack: finite responses are buffered until the outer COMMIT; SSE commits before headers; a failed commit is turned into `E_UNAVAILABLE` (server/middleware.py:124-201).
- Raw provenance walks survivors with (a) at each hop, and filters verbatim `payload_item.links` (core/read_service.py:413-480).
- Link targets are authorized on the selected endpoint with a uniform `E_NOT_FOUND` (core/write_service.py:548-602).
- Every read predicate uses version-row authz only, never the copied chunk scope (db/read_queries.py:159-166).
- Idempotency: advisory key lock, versioned hash, fails closed on an unknown version (core/write_service.py:658-689).
- Worker: copies, inserts and the lease-fenced `_mark_done` all happen in one transaction; the metered text equals the wire text via `canonical(result)` (worker/main.py `process_jobs`; server/mcp_server.py:214; core/budget.py:117-139).

## Verdict
NO-GO: #1 lets any project writer detect and overwrite device-scoped items it cannot read, which breaks the dual-axis authorization Phase 0 promises. #2 must also be fixed before the VPS deploy (D-032).
