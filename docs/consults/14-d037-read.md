# D-037 read-side design exchange — 2026-09-22

Implementer slice: F16 `memory.raw` / `memory.drilldown` link budgets.

Proposal to the root co-architect: filter raw links by nonempty overlap with the addressed
version on **both** valid-time and knowledge-time intervals; keep historical addressed versions
and pinned far endpoints authorized without requiring current liveness. Drilldown already uses
`temporal_live` on its link rows. Pack chunks and links as independent units under the existing
signed cursor rather than repeating all edges in every envelope. Link-only continuation pages
must be possible. Bind cursors to the read parameters and freeze knowledge time.

Root response: "Agree raw temporal overlap addressed version (historical provenance retained,
removes unrelated revision edges). Cursor bind full read parameters version + interval and
offsets. Record concise design consult; root updates ADR/spec. Ensure long link-only lists
paginate even once body exhausted."

Implementation: raw returns chunks first, then outgoing edges. Drilldown returns each clue's
chunks followed by its outgoing edges. Link-only drilldown items use empty text and the last
chunk's ordinal as their position. Collections partition across pages without repetition;
metadata and raw payload provenance retain their existing shape. Budget accounting still
measures canonical wire JSON exactly. A raw cursor carries the initial knowledge cutoff to
exclude edges created between pages; current authorization is reapplied on every request.

Contract adjustment owned by root: §1.1/§4.4 raw link interval overlap and §3 pagination language.
Verification: new integration regression file covers many-link paging, historical vs current
card edges, temporal exclusions, stale authorized endpoints and cursor bindings. Root owns
serialized DB runs and acceptance gates.
