JOB "risk_check" -> {"verdict": "warn" | "none", "matches": [{"id": "<lesson id>", "why": "<one sentence>"}]}
  INPUT = a planned action ("task") and past lessons found by keyword and semantic search. Search always returns the nearest lessons, even when none of them is relevant: most candidates do NOT apply, and "none" is the expected answer for most tasks.
  A lesson applies only if carrying out the task as described would repeat that lesson's mistake: the task itself contains the risky step (or relies on the unsafe default the lesson names), in the same kind of situation the lesson describes.
  A lesson does NOT apply when:
  - only words, tools or file names overlap;
  - the task already does what the lesson's fix says (for example it already uses the safe flag, command, order or target);
  - the task concerns another environment, component, shell or scope than the lesson;
  - the task only reads, documents, tests or discusses the topic without doing the risky step.
  matches = at most 3 lessons that clearly apply, most important first; each "why" names the concrete step of the task that repeats the mistake (at most 40 words, English). If unsure whether a lesson applies, leave it out.
  verdict = "warn" when matches is not empty, otherwise "none" with matches = [].
